# Nensi Sakhiya — Portfolio

Single Next.js repository with multiple specialty portfolios (English default + German).

## URLs

| Path | Portfolio |
|------|-----------|
| `/` | Hub — pick language + specialty |
| `/en/full-stack` | Full Stack (English) |
| `/en/react-native` | React Native (English) |
| `/en/ai-engineer` | AI Engineer (English) |
| `/en/devops` | DevOps (English) |
| `/de/full-stack` | Full Stack (Deutsch) |
| `/de/react-native` | React Native (Deutsch) |
| `/de/ai-engineer` | AI Engineer (Deutsch) |
| `/de/devops` | DevOps (Deutsch) |

Each specialty path has a matching résumé download under `/public/resumes/`.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
